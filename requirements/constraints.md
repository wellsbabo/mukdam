## 1. 제외 기능

### 1.1 계정 및 인증

- 회원가입, 이메일/비밀번호 로그인
- SNS 로그인(카카오, 구글, 애플 로그인 등)
- 다중 사용자 지원, 사용자 전환
- 프로필 관리

### 1.2 소모임·공유

- 소모임 그룹 생성 및 초대
- 다른 사용자와 기록 공동 열람
- 댓글, 좋아요, 반응
- 실시간 나눔 기능

> 소모임 나눔은 iOS 기본 공유 기능으로 텍스트를 내보내는 수준까지만 지원한다.

### 1.3 성경 콘텐츠

- 성경 본문 전문 제공 및 검색
- 성경 번역본 데이터 내장
- 성경 읽기 진도(통독) 관리
- 오디오 성경, 해설 자료

> 저작권 문제로 한국어 성경 번역 본문(개역개정 등)은 앱에 포함하지 않는다.
> 묵상 기록에는 구절 참조(책·장·절)만 남기고, 본문이 필요하면 사용자가 직접
> 입력한다.

### 1.4 알림 및 백그라운드 동작

- 푸시 알림, 로컬 리마인더 알림
- 위젯, 홈 화면 잠금화면 위젯
- 백그라운드 동기화 작업

### 1.5 부가 기능

- 결제, 구독, 인앱 상품
- 광고
- 통계·대시보드(기록 수, 연속 기록일 등)
- 이미지·음성·파일 첨부
- 다국어 지원(한국어만)
- 다크 모드 전용 커스텀 테마(시스템 설정 반영은 허용)

### 1.6 향후 검토 기능

- 기기 간 동기화 및 백업
- 기록 검색
- 기도제목 응답 기록
- 소모임 공동 나눔 공간
- 안드로이드 지원
- 수익 모델(구독 또는 유료 기능)

## 2. 기술 및 환경 제약

| 항목 | 제약사항 |
|---|---|
| 애플리케이션 형태 | iOS 모바일 앱. 웹 버전 없음 |
| 대상 기기 | iPhone. iPad 전용 레이아웃은 제공하지 않음 |
| 필수 기술 | Swift / SwiftUI 네이티브 개발. 크로스플랫폼 프레임워크(Flutter, React Native 등) 사용하지 않음 |
| 사용할 수 없는 기술 | 자체 서버 및 백엔드 API. 운영비가 발생하는 클라우드 리소스 |
| 데이터 저장소 | 기기 내 로컬 저장소만 사용 |
| 지원 브라우저/기기 | 해당 없음(네이티브 앱) |
| 배포 환경 | Apple App Store. 안드로이드/Google Play는 이번 범위 아님 |
| iOS 최소 버전 | 미정 |

## 3. 보안 및 데이터 제약

- 인증이 필요한 사용자: 없음. 로그인 없이 기기 소유자가 바로 사용한다.
- 저장하면 안 되는 정보: 타인의 실명·연락처 등 식별 가능한 개인정보. 기도제목에
  타인이 언급될 수 있으므로 별도 개인정보 필드를 두지 않는다.
- 암호화가 필요한 정보: 별도 애플리케이션 수준 암호화는 적용하지 않는다. 기기
  기본 보호에 의존한다.
- 외부 전송: 기록 데이터를 외부 서버나 분석 도구로 전송하지 않는다. 사용자 행동
  분석 SDK도 포함하지 않는다.
- 데이터 보관 기간: 사용자가 삭제하기 전까지 기기에 보관한다.
- 데이터 삭제 조건: 사용자가 기록을 삭제하거나 앱을 삭제하면 함께 제거된다.
  앱 삭제 시 기록이 사라진다는 점을 사용자가 인지할 수 있어야 한다.
- 적용해야 하는 법률·정책: 개인정보를 수집·전송하지 않으므로 별도 동의 절차는
  두지 않는다. App Store 심사 지침과 개인정보 처리방침 게시 요건은 준수한다.

## 4. 일정·예산·운영 제약

| 항목 | 제약사항 |
|---|---|
| 목표 완료일 | 미정 |
| 개발 인원 | 1명 (본인) |
| 월 운영비 상한 | 0원 목표. 서버·DB 등 상시 과금 리소스 사용하지 않음 |
| 유료 서비스 사용 | 사용하지 않음. 단 Apple Developer Program 연간 비용은 예외로 인정 |
| 서비스 운영 시간 | 해당 없음(기기 내 동작) |
| 허용 가능한 중단 시간 | 해당 없음(서버 없음) |

## 5. 외부 연동 제약

- 반드시 연동해야 하는 시스템: 없음
- 연동하지 않을 시스템: 카카오톡 API, 교회 관리 시스템, 성경 API, 분석·광고 SDK
- 사용할 수 있는 외부 API/서비스: iOS 기본 공유 기능(UIActivityViewController
  수준). iCloud 동기화는 도입 결정 시 예외로 검토
- 외부 서비스 장애 시 대안: 외부 서비스에 의존하지 않으므로 해당 없음

## 6. 미결정 사항

- [ ] iCloud 기반 기기 간 동기화 도입 여부. 도입 시 `자체 서버 사용 안 함` 제약과
      `운영비 0원` 제약은 유지 가능
- [ ] 동기화를 도입하지 않을 경우 데이터 이전 수단(파일 내보내기/가져오기 등)
- [ ] iOS 최소 지원 버전
- [ ] 수익 모델 도입 여부 및 시점
- [ ] App Store 앱 이름 중복 확인(`묵담`)
- [ ] 개인정보 처리방침 문서 준비 방법(App Store 제출 요건)

> 구현 기술은 Swift/SwiftUI로 확정되었고, 성경 번역본 본문 미포함도 확정되었다.
> 자세한 결정 이력은 [`requirements.md`](requirements.md) 6.1절 참고.
